# /lhg-study-abroad:study-abroad —— 背景素材输入

用户输入在 `$ARGUMENTS` 中：`[申请人背景描述] [--lang zh|en]`，缺省中文。

全程加载 `lhg-sa-material` 指导；素材梳理可分派给 `material-coach` agent。

## 流程

### 1. 确认目标与语言
- 问清三件事：目标学校、目标项目、文书语言（中文 PS 还是英文 PS）。三件事缺任何一件，先问，不许跳过。
- 语言决定后续所有产出的语言，也决定字数口径（中文按字、英文按词）。

### 2. 五维素材采集
- 按 lhg-sa-material 第 3 节五维清单逐维采集：教育背景 / 科研经历 / 实习实践 / 课外活动 / 获奖荣誉。
- 每一维追问"STAR 四要素"：情境、任务、行动、结果（数字优先）。
- 采集时只记录用户亲口说的，**不许脑补、不许编造**。用户说"记不清了" → 标记为"待补充"，不许替他编数字。

### 3. 输出素材清单
- 输出 `materials.md`：五维表格 + 每段经历的"经历卡片"（时间/角色/行动/数字/可提炼的品质）。
- 经历卡片按"含金量"排序：有数字、有转折、有独特性 的排前面。
- 标记"待补充"项清单，交给用户回去补。

### 4. 交棒
- 素材清单经用户确认后，交棒给 `/lhg-study-abroad:study-structure` 做结构搭建。
- 用户没确认 → 不许往下走。

## 硬规则
- 用户没说过的经历、成绩、数字 → 不许出现在任何产出里。
- "大概""可能""应该"类模糊表述 → 必须追问到具体或标记待补充。
- 素材清单未经用户确认 → 不许进入结构搭建。
